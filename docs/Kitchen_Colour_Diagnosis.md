# 厨房偏黄与灰柜偏褐色的诊断

日期：2026-10-07。使用 RTX 4060 Ti 的实际 Vulkan HDR 输出检查。

## 结论

柜体并非本来就是褐色。`CupboardUnits` 材质的线性 Base Color 是
`(0.547857, 0.547857, 0.547857)`，没有基础颜色贴图；`Walls` 是白色。
地砖 `Tiles` 则本身偏暖，Base Color 是 `(0.394083, 0.325037, 0.263175)`。
木材的褐色贴图也需要与照明造成的偏色分开判断。

厨房预览的两盏顶灯使用暖色 `(1, 0.88, 0.72)`，强度 70。
局部探针捕获灯光、场景表面和可见天空，提供室内漫反射 IBL 与反射。
它是静态/按需刷新近似；调整直接光不会自动重新捕获它。
因此，被遮挡的灰柜暗面仍主要由已缓存的暖色环境照明决定。
这是光照贡献和缓存更新策略的共同结果，不能把所有褐色区域都叫作阴影。

阴影可见度减少直接光贡献，本身不向表面添加棕色。关闭当前直接光的阴影，
柜体明显变亮，但仍偏暖；已经捕获的探针内容并不随这个开关重新计算。
增加白色点光会让受到它照射的区域趋向中性；很强的灯光还可能经逐通道
filmic 色调映射趋向白色。这都不意味着基础材质刚刚“恢复”了白色。

## 分离检查

从 Base Color 输出中选择 369325 个中性灰柜体像素，比较它们的线性 HDR RGB
中位数。窗口输出为 942×1012；这些数据用于归因，不作为原生 1080p 性能验收。

| 输出条件 | 灰柜像素线性 RGB 中位数 |
| --- | --- |
| Base Color | `(0.547852, 0.547852, 0.547852)` |
| 暖灯与局部探针，完整照明 | `(0.066895, 0.035583, 0.020264)` |
| 关闭当前直接光的阴影，保留原探针 | `(0.085938, 0.065002, 0.052643)` |
| 仅原探针漫反射 | `(0.061493, 0.032196, 0.018188)` |
| 关闭全部直接光后，仅原探针漫反射 | `(0.061493, 0.032196, 0.018188)` |
| 灯色全部改白，未刷新探针，仅探针漫反射 | `(0.061493, 0.032196, 0.018188)` |
| 灯色全部改白并刷新探针，仅探针漫反射 | `(0.061493, 0.036499, 0.024994)` |

关闭直接光与改白灯色这两个条件下，原探针漫反射输出的完整原始数组差值为 0。
探针状态正确报告需要刷新。刷新后暖色比例降低，但木材、地砖和环境仍有颜色，
单个房间探针也没有逐位置的可见性求解，因此不能期待每一块白/灰材质都显示中性。

多数所选柜体像素的直接光贡献为零；这是这些像素的中位数结果，
不代表整个场景没有直接光。它解释了为何增加不覆盖这些区域的光强，暗面的色调变化很小。

## 交互与复现

1. 使用 `Base Color` 检查材质本色；使用 `IBL Diffuse` 和直接光调试视图分别查看照明。
2. 若需要中性材质检查，将太阳光和局部灯色设白，再使用 `Capture / refresh probe`。
3. 改变灯强度只会缩放该灯的 RGB，不能直接改变该灯色调，也不能更新旧探针。
   `Sun intensity` 只控制默认太阳光；局部灯和 IBL 各有自己的控制项。
4. 为避免混淆，UI 已将原通用标签明确为 `Sun direction / Sun intensity / Sun color`，
   并说明厨房暖灯预设以及几何、材质、灯色、强度变化后的探针刷新要求。

诊断入口保留原有厨房检查，按需额外导出分离图像：

```sh
cd build-linux
env -u WAYLAND_DISPLAY VK_DRIVER_FILES=/usr/share/vulkan/icd.d/nvidia_icd.json \
  ./gpu_scene_transaction_test 1 auto kitchen-colour \
  ../assets/models/pbr_kitchen/source/kitchen_core.gltf /tmp/kitchen-colour
```

输出包括 filmic/sRGB PPM 和未色调映射的 RGBA32F。原有 `kitchen` 入口不增加这些诊断帧。
实际 GPU 运行通过：293 opaque、6 blend、2 spot shadows；直接光变化不会修改静态探针的检查通过。
UI 修改后构建通过。本轮没有改变材质、默认暖灯颜色或 PBR 着色公式。

当前室内探针仍是单探针近似，并非已实现动态漫反射 GI。后续 AO、反射探针覆盖和
GI 工作需要独立处理可见性与空间差异；给整个房间强行去黄或增加白光不能替代这些工作。

证据文件位于本次聊天的 `outputs/kitchen-colour/`：`diagnostic.log`、
`neutral-cupboard-measurements.json` 以及 `images/` 下的原始输出和预览。
