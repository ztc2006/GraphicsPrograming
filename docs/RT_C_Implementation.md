# RT-C：基础玻璃与光栅探针近似

2026-10-09。本轮实现已确认的基础光滑玻璃范围；两条管线继续独立，用户保留画质判断。原厨房glTF/bin不修改，不提交或推送Git。

## 可运行行为

显式PBRT `dielectric`/`eta`及因子型KHR transmission/volume/IOR进入共享材质。覆盖alpha与光学透射分开；厨房转换alpha=.35不再当作随机孔洞。普通BLEND没有被推断成玻璃。IOR/透射/吸收/厚度和coverage均验证；体积衰减色/距离转换为Beer系数。因子型支持不等于完整扩展实现：透射/厚度贴图、IOR0特殊情况、unlit/spec-gloss及部分金属透射组合明确拒绝。全金属不产生透射。

RT保留几何外向符号，使用准确介电Fresnel、Snell折射、全反射和进入/离开介质。Radiance的eta平方权重与RR补偿配对；吸收按实际世界光程计算，光线偏移的遗漏距离补偿。相机从介质内部开始受到测试。薄片采用两个界面的有效Fresnel，净透射保持直线；仅有作者厚度时吸收，不凭开口网格AABB编造厚度。

光栅使用相同参数的捕获探针折射/反射。闭合体光程为作者厚度或AABB的明确proxy；开放薄片没有猜测厚度。光学Opaque/MASK覆盖复用不透明深度写入选择最近表面，消除前后面按三角形顺序覆盖；BLEND仍混合。探针捕获使用直接光opacity近似，保留透明管线，避免递归采样探针照明。没有RT调用、屏幕背景拷贝或新光栅附件。

## 厨房内容

按原始位置精确焊接仅做边界诊断，要求每条边恰有两面、相反方向且每个壳有正体积；不修改顶点/法线，不补洞。该检查不能证明无自交。生产导入准备和GPU资产准备分别执行判定。

|---|---|---|
| 14、185 | WineGlasses | 闭合实体，各2个壳 |
| 182 | MicrowaveGlass | 闭合实体，AABB薄方向约0.994mm |
| 252 | CookerGlass | 闭合实体，2个壳 |
| 183 | MicrowaveDigital | 开口/非流形，薄片回退 |

5个明确光学材质、6个网格，4实体/2薄片；均IOR1.5、transmission1、源roughness0。原资产缺少吸收数据，因此sigma0，不制造玻璃颜色或吸收距离。入口会发布两个回退诊断。

## 资源与边界

Material UBO48→80B；RT实例144→176B、payload扩展。主608B UBO、128B push、1088B indoor、Vertex112B保持；既有SBT/纹理能力/容量回退与成功提交发布合同保留。光学数据进入RT历史失效key，场景存储和退休负责其生命周期。没有新增累积图像，HDR仍RGBA32F。CPU网格边界检查会增加场景准备成本。

当前仅光滑介质，粗糙透射会明确警告并采用光滑近似。只有一个活跃介质；重叠/嵌套遇到不同实体保守终止，不宣称介质栈支持。直接光穿玻璃使用最近交点的彩色直线可见性，不计算折射焦散；最多32次透明交点。默认8个表面事件与1spp/帧保持，因此复杂内部反射可能因事件上限截断。没有焦散专项、体积散射或NRD。

光栅探针为静态捕获、覆盖受限；不能保证看到全部屏幕内/外背景，也不能保证与真实光路相等。玻璃背后透明物体等内容仍受探针近似限制。几何AABB光程不等于实际酒杯壁厚。RT真实距离与光栅proxy分别记录，不强行数值等价。

GPU：薄盒透射期望(1-F)/(1+F)=.923077；观测约.923571。毫米吸收独立期望(.339111,.124729,.923077)，观测约(.339312,.124809,.923496)。匹配IOR的Beer误差<1e-4；光学alpha、薄片双界面、Snell背景位移、相机内全反射、镜像出入方向、彩色shadow吸收和最终资源归零。光栅生产shader验证Fresnel/IOR/Beer、实体/薄片探针方向、开放回退、相反面顺序及捕获非递归。所有场景均覆盖1/2帧槽。
